# 2024 HORIZON战队 工程机器人

Author：电控王涵炜，机械刘田（只是主要负责人，不排除其他队员的共同帮助）
***

> **说明事项**
 - 主控分为两个板（主，从）
 - 主、从主控通过串口进行通信
 - 主控板所控制的电机： 底盘4个3508，存矿4个2006
 - 从控板所控制的电机：抬升2个3508，前伸2个3508，机械臂的横移1个，机械臂的yaw轴，差动关节2个2006

> **命名规则**
 - RUI_D F定义名
 - RUI_F 函数名
 - RUI_V 变量名
 - BSP 硬件层
 - TASK 任务层
 - OneClick 一键指令层
> **LED规则**
 - 青色慢闪：全部在线
 - 青色快闪：DBUS在线&&存在电机离线
 - 紫色快闪：DBUS离线&&存在电机离线
